## RL3 — No-Code Reinforcement Learning Playground

🔗 https://rl-playground-beta.vercel.app/

🎬 https://youtu.be/V5d99hOM5ew?si=3tmVo07-YfdBBilP

A visual reinforcement learning platform that enables users to design environments, build reward functions, train agents, and run inference without writing RL code.

**Highlights**

* Built a drag-and-drop 3D environment editor using React, Three.js, and Rapier
* Developed a node-based reward graph for visually defining rewards, conditions, and terminal states
* Implemented browser-based tabular Q-Learning with state discretization and downloadable Q-tables
* Built a server-side PPO training pipeline using FastAPI, PyBullet, Gymnasium, and Stable-Baselines3
* Added dynamic observation and action spaces based on agent capabilities
* Implemented action masking, environment randomization, model retraining, and real-time WebSocket inference
* Supports multi-agent policy playback, manual agent control, and reusable trained models

## Sentience (Craftax Agents) — LLM + Reinforcement Learning Research

🔗 *Coming Soon*

An experimental research project exploring how Large Language Models can complement Reinforcement Learning by separating high-level reasoning from low-level control inside the **Craftax** environment.

The objective is to investigate architectures where an LLM performs planning, task decomposition, and decision making while RL policies execute motor control and environment interactions.

**Current Goals**

* Integrate Craftax as the research environment
* Explore LangGraph/LangChain agent orchestration
* Investigate memory using RAG and vector databases
* Build hierarchical agent architectures (Reasoning → Skills)
* Compare pure RL against hybrid LLM + RL approaches
* Publish experiments, benchmarks, and research findings
